# Klump

> Klump Technology Company Ltd is a Lagos, Nigeria based fintech. Its flagship product,
> Klump BNPL (Buy Now, Pay Later), lets shoppers spread the cost of a purchase over monthly
> instalments at online and in-store merchant checkouts. Merchants integrate through the
> Klump.js browser widget, a framework component, an e-commerce plugin, or the REST API at
> https://api.useklump.com.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from apis.yml and the
artifacts in this repository. Klump serves no llms.txt of its own (probed 2026-07-19:
useklump.com/llms.txt 404, docs.useklump.com/llms.txt 404).

## Key facts

- Base URL: https://api.useklump.com — one base URL for both sandbox and production.
- Environment is selected by the merchant application state (TEST or LIVE) plus the key pair used.
- Server auth: merchant secret key in a `klump-secret-key` request header. There is no OAuth.
- Client auth: merchant public key (`klp_pk_` prefix) passed as `publicKey` into the Klump.js object.
- Versioning: URI path, currently `/v1/`.
- Errors: plain HTTP status codes (200, 201, 400, 401, 403, 409, 429, 5xx) with a code and message. No RFC 9457 problem+json.
- Webhooks: three transaction events, HMAC-signed with `X-Klump-Signature`, retried hourly for 72 hours.
- Klump publishes no OpenAPI definition, no AsyncAPI document, no CLI, no status page, and no changelog.

## APIs

- [Klump API](https://docs.useklump.com/docs): verify transactions, sync Klump Commerce products, create Klump Access payment pages, resend webhooks.

## Confirmed operations

- `GET https://api.useklump.com/v1/transactions/{reference}/verify` — verify a transaction before releasing value. Check `data.currency` and `data.is_live`.
- `POST https://api.useklump.com/v1/commerce/products/sync` — sync a merchant product catalog into Klump Commerce (path confirmed in Klump's own WooCommerce, Magento 2 and PrestaShop plugins).
